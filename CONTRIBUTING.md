# Contributing

Read [docs/RUNNING.md](docs/RUNNING.md) before local work. Keep changes focused and run relevant tests, frontend lint, and frontend build before opening a pull request.

Do not weaken evidence, RCA-hypothesis, SentinelGuard, human-authorization, rollback, verification, or fail-closed boundaries. Generated data/models/artifacts should remain uncommitted unless intentionally promoted as durable evidence with matching documentation.
