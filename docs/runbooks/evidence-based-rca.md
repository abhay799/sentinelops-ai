# Evidence-Based Root Cause Analysis Runbook

Root cause must not be inferred from anomaly magnitude alone.

A candidate root cause should be evaluated using:

- temporal ordering
- anomaly evidence
- recent changes
- service dependency direction
- incident correlation
- alternative explanations
- contradictory evidence

A high RCA score is still a hypothesis.

The challenger must attempt to disprove the leading hypothesis.

Automated investigation systems must not claim a confirmed
root cause without sufficient evidence and required human review.
