# SentinelOps AI Demo Script

This is a 2–4 minute portfolio demonstration plan, not a claim of a production deployment. Use the deterministic Control Center demo and preserve all LOCAL, SYNTHETIC, SIMULATED, DETERMINISTIC, and NOT CONNECTED labels.

| Time | Screen / scenario | Narration goal |
|---|---|---|
| 0:00–0:20 | Portfolio home | Introduce SentinelOps as an engineering portfolio project for evidence-grounded reliability intelligence and failure prevention. State that it is not production-connected. |
| 0:20–0:45 | Mission Control / `correlated-multi-signal` | Show the lifecycle from sensing through investigation and explain that multiple local synthetic signals can form an incident context. |
| 0:45–1:10 | RCA Intelligence / `competing-rca-hypotheses` | Explain that RCA output is a ranked candidate hypothesis, not an independently confirmed root cause. |
| 1:10–1:35 | RCA Challenger / `adversarial-rca-challenge` | Show competing explanations and contradictory evidence; describe the challenger as a check on confidence, not an autonomous decision-maker. |
| 1:35–2:00 | Counterfactuals and Remediation / `safe-local-recovery` | Explain that intervention comparisons are simulated decision support. A planner proposal is not a Guard approval, authorization, or execution. |
| 2:00–2:30 | SentinelGuard / `human-authorization-pending` | Make the human boundary explicit: even technically eligible work cannot execute while authorization is pending. |
| 2:30–2:55 | Recovery / `safe-local-recovery` | Show the only configured adapter: a local sandbox `rollback`, followed by recovery verification. Do not claim production remediation. |
| 2:55–3:20 | Investigation / `competing-rca-hypotheses` | Show grounded investigation and repeat that agents cannot confirm RCA independently or bypass SentinelGuard/human approval. |
| 3:20+ | Evidence and architecture docs | Close with evidence classifications: Phase 10 values are measured development data in synthetic context, not production-calibrated. |

Do not use customer, adoption, certification, uptime, live-telemetry, or production-performance claims in narration or captions.
